PRIVATE NATIVE FORCE BRIDGE V1 — SOURCE CONTRACT, NOT YET BUILT/QUALIFIED

Invocation: srmb_bridge system.xyz, in an isolated directory containing the
exact system.key and parameter file. Native initial/getxyz/mechanic initialize
the ordinary baseline. One process handles one geometry and one supplied u/v
pair. Stdin is reserved for the subsequent supplied-uv filename. Stdout can
contain normal Tinker initialization text before the exact line SRMB_READY.
The harness must impose timeout/error handling and preserve all partial output.

INITIAL SCOPE
Vacuum MUTUAL/Thole; zero external field; dielectric1; all atoms active and
polarizable; npole=n<=28; positive intrinsic alpha; no bounds/periodic/Ewald,
neighbor lists, implicit solvent, charge penetration/flux, EXCHPOL, alternate
direct damping, OPT/TCG, history/predictor/IELSCF/frequency response, virtual
four-site water, charge-transfer/ligand-field/extra/pi-system terms. Permanent
electrostatics uses multipoles, not an additional point-charge/dipole term.
Only these declared mode assertions are supported; unsupported inputs stop.

PREPARE, BEFORE READY
chkpole + rotpole(MPOLE); explicitly tcgnab=0; clear uind/uinp/udir/udirp over
all n atoms. dfield0a gives separate native Ed0/Ep0. Set udir=alpha*Ed0 and
udirp=alpha*Ep0. Keep native dpequal, POLPAIR damping and exclusion scales.
Build raw A0 with the original exportresponsematrix algorithm: for each ipole
site and xyz component set the same unit uind/uinp, call ufield0a, store -field
plus 1/alpha on the diagonal. Exactly one direct call and 3*npole mutual-field
applications, zero SCF solves. Clear uind/uinp afterward. Raw asymmetry and
dual-operator difference are recorded; the Python harness applies its declared
inherited arithmetic admission/symmetric-representative policy without altering
the original data. No baseline force or energy is evaluated in this phase.

baseline_state.dat (status=new; full precision ES26.17E3):
  SRMB_BASELINE_V1
  COUNTS n npole 3*npole
  CONSTANTS electric dielec debye_per_eA bohr_A
  OPERATOR_CHECKS max_abs_A_minus_AT max_abs_mutual_channel_difference
  PERMANENT_ORIGIN_A 0 0 0
  PERMANENT_MU_EA mux muy muz
  CHARGE charge_e
  MODE VACUUM MUTUAL THOLE DIELECTRIC_1 ZERO_FIELD ALL_ACTIVE NO_VIRTUAL_SITES
  FLAGS_DPEQUAL_PCGGUESS_TCGGUESS logical logical logical
  CALLS 1 3*npole 0
  for each ii=1..npole (atom=ipole(ii)):
    SITE ii atom type alpha_A3 x_A y_A z_A
    for component=1..3 (row=3*(ii-1)+component):
      VECTOR row Ed0 Ep0
      A row A[row,1] ... A[row,3*npole]
  END_SRMB_BASELINE_V1

Indices in native files are ONE-BASED; Python fixture indices are ZERO-BASED.
The permanent moment is sum(charge*xyz+rotated dipole) at literal origin0. Do
not compare charged moments at another origin without the explicit shift.
It is computed without calling moments (which would induce again). Only the
native permanent multipole contribution is included in that moment record.
Write/close baseline_state.dat, print SRMB_READY and flush before stdin read.

Python solves corrected G=A0+H with Ed0+h/Ep0+h using the pinned kernel. The
fixed phase2 coefficients, SPD/residual/matrix checks and state identity live
in the harness. No executable launch or dense solve occurs in bridge source
generation. Each future dense solve is counted separately from native calls.

No trailing records. Send its filename followed by newline to native stdin.
Native verifies current geometry, types, alpha, site order and every supplied

CONTRACTION
Copy u/v into uind/uinp by ipole mapping. Run srmb_native_gradient, a private
clone of original gradient with only the epolar1 dispatch replaced. Its private
srmb_epolar1a is the original routine with only its symbol renamed and call
induce removed. Every force loop, damping/exclusion branch, torque redistribution,
virial contribution and other gradient component is preserved. No native SCF
is called. udir/udirp remain the initialized baseline direct dipoles. Reject
if native uind/uinp changed or any result is nonfinite.

force_bridge_result.dat (status=new):

  COUNTS n npole 3*npole
  CALLS 1 3*npole 1 0     # direct, mutual actions, gradient, SCF solves
  OTHER_ENERGY U_native_reported - ep

  RAW_NATIVE_ENERGY U_native_reported
  SUPPLIED_UV_UNCHANGED T

    BASELINE_GRADIENT atom gx gy gz
    POLAR_CONTRACTION_GRADIENT atom px py pz
  for row=1..3: RAW_NATIVE_VIRIAL row three_values
  END_SRMB_FIXED_UV_GRADIENT_V1

ENERGY AND CHAIN RULE (K=electric/dielec)
L0=K/2[u^T A0 v-u^T Ep0-v^T Ed0]. Native epolar1a returns dL0/dR at FIXED
u,v, including permanent-frame torques; original intrinsic alpha is constant.
BASELINE_GRADIENT includes dU_other/dR+dL0/dR. It is a gradient, not negative
force. RAW_REDUCED_POLARIZATION=-K/2*u^T Ep0 is NOT L0 and is not the corrected
total polarization energy. At corrected u/v those baseline-only scalar and
gradient outputs are not derivatives of one another.

Correct total energy:
  U_other + DeltaV - K/2*u^T(Ep0+h).
Correct total gradient:
  BASELINE_GRADIENT + grad_R{DeltaV + K/2[u^T H v-(u+v)^T h]},
where u and v are detached/fixed in the explicit local differentiation.
COMBINE.py implements this composition. Do not add the stationary H term to
the reduced energy or differentiate the reduced energy with frozen baseline
arrays as a full force. The raw native virial is incomplete until local terms
are added; this first qualification admits Cartesian force directions only.
