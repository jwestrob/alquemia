# Ten-fold union/adaptive preparation and replay is usable

The opt-in CLI accepts explicit source groups, prepares their fixed surrounding
fragments, validates them and replays compatible archived scores. Original local
static, fixed-union static and both adaptive selection policies remain side by
side. Production and all old numerical/scientific protocols are unchanged.

## Interface and limits

[Commands](COMMANDS.md) cover `archive`, `request`, `prepare`, `dry-run`, `replay`
and `report` with explicit paths. `prepare --source-mode fresh` uses existing
preparation code; missing/unsupported inputs remain explicit. New source scoring
is not executed by this delivery. Unknown inputs cannot inherit a same-named
archive result, and an unavailable candidate cannot inherit a static score.
A valid static score remains visible independently of candidate admission.

Only the tested ten-fold membership and existing crystal selectors are supported.
Three-fold union is explicitly unsupported, even though strict three-member
summaries of the tested ten-fold representation are reportable. The separately
investigated cheaper numerical profiles are not enabled or called equivalent.
No new band fitting, affinity probability, thermal ensemble or production default.

Final tests use actual source/preparation/energy fixtures and clearly corrupted
copies for rejection/partial-failure checks; they cover source identity including
an extra real protein chain, exact unions, raw-score replay, all strict groups,
old missing members, coordinate mismatch, independent static/candidate status,
three-fold/profile rejection and all three crystal controls. Final test receipt
is recorded in RESULT.json. Earlier test-only missing-member metadata mismatch
was fixed by deriving missing members from actual per-source values; science was
unchanged.

Canonical membership is checked against the pinned historical source record; it
is not a user-assigned state anchor. This interface is limited to existing
reference groups and explicit crystal controls. It does not advertise arbitrary
unknown ten-fold PLM proteins as qualified inputs. A general-input adapter must
separate state anchoring from calibration membership and La4 exclusions.
