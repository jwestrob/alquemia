# Can charge-consistent isolated references preserve the useful ordering?

Declared2026-09-17 after the spectator and embedding findings. Use only the
five already computed intact bound La/Ca pairs. No new endpoint evaluation,
model change, reference energy, threshold fit or biological label.

A physically assigned separated reference would evaluate protein at its own
charge and Ca2+/La3+ as their individual ions. With identical protein geometry
and chemical state for the two metals, the protein term cancels. A common ionic
(or aquo) reference can only add a site-independent offset to
R_bound=E_bound,Ca−E_bound,La. Therefore it cannot change differences in R_bound
between proteins. This algebra does not assert that the model supplies accurate
isolated ionic energies or the correct charge allocation.

Before spending calls on such references, calculate all three original
cross-protein differences in raw R_bound from the saved energies, converting
eV once. Compare to the same >0.02kcal/mol relative-direction criterion and the
published R_coord results. Keep one biological alpha/GGR comparison with two
structures and the separate PQQ functional-class pair. Report all results;
this is a consumed development screen, not independent accuracy.

calculate or substitute a zero for unavailable reference energies. Keep the
separated absolute score, calibrated classification and binding free energy
unavailable. Component-dependent charge assignment or a different learned
representation would be separate model development, not this arithmetic screen.
