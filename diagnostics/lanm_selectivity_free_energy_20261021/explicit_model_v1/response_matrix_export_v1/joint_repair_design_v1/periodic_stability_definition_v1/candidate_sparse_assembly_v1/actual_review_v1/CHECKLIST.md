# Saved assembly review scope

Read the terminal supervisor/worker result and manifest, exact source/release/configuration/preparation pins, and immutable exported arrays. Check one completed assembly, zero native/factor calls, original graph payload hashes, finite float64 lower data/int32 indices, explicit diagonal layout, candidate coefficient/stiffness readback and diagonal consistency, unchanged nominal PME values, resource limits and measured costs.

Recompute only scalar relationships among already saved environment/stiffness fields and the analytic self/diagonal expression. Do not recompute geometric weights, their collective sum, pair tensors, U_B, an assembly, reciprocal application, or factorization. Verify all3980 saved weights are finite/nonnegative, without rebuilding them from coordinates.

Symmetry value0 means exact symmetric completion of the saved lower triangle. It is an algebraic property of this represented matrix, not a measured comparison with a separately stored upper triangle or a full native operator. U_B remains the value returned by the pinned qualified assembler, whose source derivation was reviewed. Preserve ordinary-double, application-error and physical/sampling limitations.

Run REVIEW.py once with all numerical-thread environment variables set to1; output is fresh and all failures are retained. No producer or helper evaluation API is imported.
