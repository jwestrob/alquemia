# Saved terminal fit report

Read one exact terminal REFINE result, its pinned initial and selected vector
artifacts, evaluator configuration/source, frozen objective and data contract.
Only terminal run statuses are eligible; a prepared or running result is not a
selected candidate. An actual failed fit remains failed, without inventing a
selection. Root binds the future artifacts and executes this adapter.

Replay initial/selected saved scoring through the unchanged objective helpers.
Do not instantiate an evaluator, invoke native programs, fit, inspect reserved
outcomes, reread every intermediate molecular record, or perform raw admission.
The saved scoring check is not independent native qualification.

Report original10 energy and15 force gates individually and together; paired
W8/W9 contrast and error; all four objective blocks; four state susceptibilities
and four C dipole errors; all34 literal pair vectors with summaries for each
parent. Preserve all28 field comparisons descriptively. Response scales are
engineering weights and supply no physical pass/fail threshold.

Report exact parameter bounds/contacts, actual stopping reason, initial-to-final
trajectory from the compact vector index, final Jacobian origin separately from
the selected point, every failed/unavailable vector and stopped cell request,
native/vector counts, and measured fit wall/parent/child CPU time. Scheduler
accounting is optional and copied with its exact source; missing allocation cost
is not estimated or called actual cost.

Consumed eight-trimer regression is outside the objective. If no result is
supplied, retain all eight pending slots. If supplied, require exact fit and
selected-artifact joins and retain every available/unavailable cycle and error.
This report creates no new regression threshold and releases no fresh validation.

Output a compact structured RESULT.json and a repository Markdown REPORT.md.
Both preserve failures and reference-method limitations. Source controls use
saved baseline values and explicitly synthetic terminal metadata only; no fit
or candidate molecular evaluation is performed.
