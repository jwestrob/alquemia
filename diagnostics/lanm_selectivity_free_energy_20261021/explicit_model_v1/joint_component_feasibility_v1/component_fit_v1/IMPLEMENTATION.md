# One bounded component campaign

The root declaration owns the scientific policy. CORE supplies the single SLSQP proposal, independent fraction certificates, and actual gate-filtered selection. DRIVER owns ordered execution and immutable vector/history artifacts. ADAPTER changes the execution envelope and cache imports around the unchanged EVALUATE.py scientific rendering, admission, and score assembly.

The final execution context selects truthful login execution: 12 native workers, one numerical thread each, no fabricated Slurm variables and null job IDs. Root checks the live aggregate allowance before release. Every native attempt is counted at the invocation boundary; the unchanged native helper has a 300-second timeout. Failed programs, incomplete cells and queued untouched slots remain in a fresh ledger. A failed or budget-incomplete batch cannot change the incumbent. There is no restart or automatic retry.

## Reuse and limits

The immutable final-fit review authorizes origin 24 and its exact 24 ordered probes. The separately admitted pilot contributes an optional exact cache authority only. The 26 vectors contain 1,196 cell references and 644 distinct scientific identities. Import checks bind each vector pin, full scientific cache identity, request identity and saved cell-record hash. Stored energies, moments, susceptibilities and scores are retained exactly; no old mutable ledger or repeated LAPACK/native admission is used. Pilot reuse never changes the start or adds a selectable trial.

The parent initial vector remains the original baseline, preserving its legitimate exact-baseline cache path. A new derivative changes one metal, so the other metal's 23 cells/28 programs remain cached. The campaign allows at most 200 new vectors, 6,496 actual native invocation attempts, eight proposal calls, and four ordered trial fractions per step. Whole-vector budget checks prevent beginning a vector with insufficient remaining calls.

## Selection and outputs

Only an explicit eligible certified fraction is a candidate. All eligible trials must complete numerical admission before CORE.select is called; probes are never passed as candidates. The selected vector must pass the original 25 E/F gates and fixed four origin block ceilings, and improve the fixed minimax component objective with the declared current-based tie tolerance. Saved reuse has the same trial-role requirement.

RESULT.json retains all imported/new vector pins, derivative roles, proposal pins, complete/failed trial slots, incumbent transitions, stop reason, native ledger and actual controller/child costs. Solver failures retain their status; qualifying fractions are only finite feasibility witnesses. The quarter-objective flag alone is not a physical accuracy claim. A separate declared consumed trimer regression follows independent terminal selection review; no fresh validation or production release follows automatically.

## Runtime binding

ROOT_RELEASE_TEMPLATE.json names the exact source/configuration fingerprint, source review, zero-call preparation, declaration, execution context, parent scientific configuration, import inventory, limits and fresh output/cache. CONFIG_RUN_TEMPLATE.json has only three runtime fields to bind: source_review, preparation and root_release. Their values are excluded from the scientific fingerprint and explicitly checked at the gate. Source review must name DRIVER, ADAPTER and CORE. Neither preparation nor source controls invokes a real proposal or molecular program.
