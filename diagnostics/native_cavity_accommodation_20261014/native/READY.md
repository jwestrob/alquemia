# Saved accommodation cavity runner

The adapter is ready for root binding after the actual eight-cell preparation passes. It imports the byte-pinned successful4562 native driver and reuses that executable, static libraries, factory, validation routines and four origin transfers. There is no build or local replay.

Exactly eight saved nonorigin endpoints are declared: samples0/3 × adaptive_Ca/adaptive_La × Ca/La. Each gets union and cap-removed native updates, sixteen total. The first endpoint's actual component/precision and measured-memory qualification precedes the other fourteen updates. The same checks remain applied to every later endpoint. Failure stops dependent dispatch and retains partial receipts.

The preflight checks unchanged192-atom core membership,14 caps, saved charges, native/component-v2 qualifications, paired geometry, and every appended source atom/zero charge against the completed origin preparation. It reuses the original1e−9Eh algebra/repeat gates and1e−6Eh endpoint uncertainty ceiling. Origin-relative work and higher paired/source uncertainty bounds are reported with explicit informative flags. No bands or pool scoring run in this adapter; root owns the separate saved-data comparison.
