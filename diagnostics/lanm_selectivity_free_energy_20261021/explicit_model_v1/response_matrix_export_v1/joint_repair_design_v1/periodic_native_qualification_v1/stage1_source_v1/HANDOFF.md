# Stage1 source handoff

One new standalone compile/link is needed; `LINK_RECIPE.json` gives the exact argv, original compiler/link pins, module inventory and environment. Do not rebuild the unchanged Tinker archive. The source uses the same GNU Fortran13 ABI and generic recorded `-O2 -g -fbacktrace -fopenmp` flags; no new architecture-specific flag is introduced. Shared paths are usable from standard_expand nodes, conditional on the actual node resolving the pinned compiler/link/runtime dependencies. Node compatibility has not been exercised here. Root can link once on the chosen CPU node and record that evidence before application.

Native inputs are in the prepared workspace manifest. Copy its five exact files into a fresh execution directory and run the bound executable with `system.xyz` as its sole argument, in that directory, with all numerical-thread variables set to1. The executable produces `parity_state.dat`, `parity_apply.dat`, `parity_receipt.dat` and `pme_norm_export_001.dat`; stdout/stderr, command receipt, input hashes and cost must be retained by the root launcher. There is one explicit-operator program; no energy/force program is released. Any nonzero exit, missing/truncated record or failed admission stops this finite stage, without retry.

Saved comparison (after successful native termination) is `python REPLAY.py <prepared MANIFEST.json> <execution directory> <new replay output directory>`, one thread. Use an environment with NumPy/SciPy; it needs no CHOLMOD, solver or GPU. Large static lower arrays are read once, and the sparse grid map is built once. No refactorization or induced solve occurs. The comparison result does not itself certify the native execution receipt; root or independent actual review must join that receipt and binary/release pins before admission.

Prospective runtime resource limits and root source/build/execution release remain unbound. This source package contains no runnable release or scheduler mutation. The unchanged fatal guards continue to block all normal active periodic energy/force paths.
