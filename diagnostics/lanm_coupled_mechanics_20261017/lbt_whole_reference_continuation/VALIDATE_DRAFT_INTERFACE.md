# Continuation draft validation interface

Source preparation only. No bound configuration, continuation decision, Slurm
submission, or numerical test is supplied. `VALIDATE_DRAFT.py` pins the unchanged
continuation source `06e40d37` and root specification `e23187e0`.

After actual scout 13051 admission, original saved collection and root measured
cost/continuation review, the harness accepts the real bound continuation config:
`VALIDATE_DRAFT.py --config REAL_BOUND_CONFIG --output FRESH_DIRECTORY`.
It requires Slurm and the original qualified Python/environment. The config is
the adapter's existing contract; no additional scientific keys are introduced.
It need not contain a continuation `preflight_result`, because this harness
exercises saved input admission and forbidden-task rejection, not execution.

The unchanged `CONTINUATION_DRAFT.inputs()` runs once on genuine evidence. This
replays the actual native scout output/gradient, original collector and 13049
states/decks/three-available-one-missing solvent inventory, then the separate
13142 supplemental ALPB receipt. Missing future parents leave all dependent
controls unexecuted and return `execution_failure`; no admitted parent is
invented. Each subsequent config-level control stops before scientific helper
imports or repeated preparation.

| Control | Real evidence and deliberate fault | Required rejection |
|---|---|---|
| Missing scout | Actual config copy with its scout pin removed | Required evidence pin missing |
| Changed scout | Actual scout copy, selected task changed to `after_La`, new valid hash | Actual 13051 scout identity gate |
| Altered decision scope | Actual root decision copy with retry permission changed to true, re-pinned | Original three-task/no-retry scope gate |
| Altered measured cost | Actual decision copy referencing the real scout RESULT instead of its native cost receipt, re-pinned | Exact native cost receipt association |
| Repeat before-La | Unchanged `prepare_task()` requested with `before_La` | Task allowlist, before directory creation |
| Wrong supplemental geometry | Actual before-Dy ALPB receipt supplied to the admitted after-Dy cell | Exact saved physical provenance |
| Wrong supplemental metal | Actual after-La ALPB receipt on the same after geometry supplied to the admitted after-Dy cell | Native coordinates/charge/metal identity |

The last two are **helper-level semantic controls** of unchanged V1
`REFERENCE.admit_alpb()`. The complete continuation input gate hard-pins the
13142 collection and supplemental after-Dy receipt; replacing those parents
would only reach an earlier immutable-parent rejection. The harness does not
relax that binding to force a deeper test. The two wrong receipts remain
unaltered actual artifacts; only the in-memory cell reference changes.

Invalid copies carry explicit test-only provenance and are never scientific
observations or continuation approvals. Exact expected `ValueError` messages
are required; another exception is a failed test. All seven slots remain in
`RESULT.json`, including unexecuted ones. The adapter/spec and original
artifacts remain unchanged. No adapter main/run/native runner/model evaluator
is called; an irreversible process audit hook also blocks subprocess/exec/spawn
attempts, which fail validation. The result records zero molecular calls and
any blocked process attempts, with application time separate from scheduler
costs supplied by the eventual allocation receipt.

Only AST syntax inspection is permitted during this source preparation. A
future `complete` result means the real-artifact admission/rejection checks
passed under Slurm. It does not qualify DFT accuracy, remaining native runs,
the later four-cell collector, or physical/electronic-state assumptions.
