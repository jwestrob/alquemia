# Opt-in ten-fold union/adaptive preparation and archive replay

Parent authorized this bounded implementation after the completed225-source
result: expose request/prepare/dry-run/replay with original/static and candidate
fields side by side, tested on complete A0A3F2YLY8 and Q9Z4J7 source groups. No new
molecular evaluations, optimizer changes, three-fold equivalence claim or default
promotion. Standing Jacob authorization applies; no new approval loop.

An explicit source request declares exactly five Ca-conditioned and five
La-conditioned structures per protein, including one original canonical La source.
All actual protein-chain sequences/numbering, site roles, source metal identities,
assembly and preparation configuration must agree within the group. Existing
explicit selected-crystal selectors are supported as singletons. Labels never
select group members, fragments, states or thresholds.

Reuse hash-compatible archived source preparation where available, while checking
actual raw-source identity. Reconstruct the fixed union from all supported group
local-context fragments with existing source graph, disulfide, peptide/cap and
state-signature machinery. Freeze group membership before any future search.
Missing sources/atoms or incompatible states remain per-source unavailable; do not
remove members or guess chemistry. Fresh preparation uses existing normalizer,
Ca residue-only adapter and protonation policy; it does not run energies.

Archive replay requires exact physical state and coordinates (the existing1e−12Å
copy tolerance), fixed method/reference/settings, and actual saved three-candidate
matrices. Recompute both selection policies, retain original static and union
static separately, and use unchanged references. Report all declared members and
strict La4/Ca5/balanced medians plus all four three-of-four La subsets; no thermal
or probability claim. A candidate failure cannot silently inherit a static score.

Initial implementation checks:20 actual sources (A0A3 andQ9) reconstructed and
replayed; existing crystal selector integrity/replay checked from real fixtures.
No source editing required: paths and selection are explicit CLI arguments/pins.
Future cheap numerical profile remains unavailable pending the separate34-source
stopping and28-reference rank qualifications. Old settings and archives immutable.
