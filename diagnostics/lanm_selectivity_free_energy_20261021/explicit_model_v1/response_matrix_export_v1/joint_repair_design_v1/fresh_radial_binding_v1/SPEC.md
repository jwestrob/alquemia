# Versioned binding for the four fresh W9 radial cells

This changes only the candidate and native-source interfaces described in
`../fresh_validation_readiness_v1/CHECKLIST.md`. The original four geometries,
ECP-PBE0-D4 reference panel, central reference anchors, scorer and all twelve
1/2/5 gates remain fixed. No held outcome is read by preparation or binding.

The only candidate is the terminal frozen twelve-parameter selected46 artifact.
Binding requires its completed raw review, all 25 original E/F gates, the exact
qualified source/build/executables, and a complete eight-cycle consumed trimer
report explicitly accepted by root. There is no added physical threshold for
dipoles, susceptibility or trimers. These future authority pins are null here.
Root acceptance records the progression decision; it is separate from the
later finite execution release. A failed prerequisite cannot open fresh data.

Preparation reuses the original typed coordinates and graph. It reconstructs
the four permanent moments and mass centers at those coordinates using frozen
helpers. Binding renders the selected vector using EVALUATE.py, checks the
selected central W9 effective input and E/F authority, and supplies those
selected E/F values as model anchors. It does not use old17676 model anchors.
For an inherited zero-response center the qualified original effective input
is retained as its authority, while the exactly qualified zero keyword is
rendered consistently for center and displaced input; that distinction is
explicit in the binding record.

Finite execution is four reference energy/gradient programs (four single-thread
MPI ranks each), plus four analyze EM and four analytic testgrad programs (four
single-thread workers, zero internal finite differences). Analyze EM adds only
the already qualified moment/readback admission to the old analyze E route.
There are no matrix exports. Analyze and testgrad have separate directories.
Each unstarted slot remains visible on failure; failed calls are never retried.
All actual scheduler costs, including failed allocations, remain root-owned
accounting evidence in addition to application timings.

Reference execution/collection delegates the frozen native deck and parser.
The copied reference run/collect bodies and the reused comparison/scorer keep
missing rows unavailable and preserve SCF/grid/state warnings. Reference and
model arms bind the same BOUND.json and selected artifact. The saved collector
reports all four individual works, two paired works and six rigid force cases;
it cannot infer a pass from a partial denominator. No model-to-reference
agreement is a proof of bulk hydration, reference-method accuracy or protein
transfer. No fit, donor/protein calculation or production release is included.

The source review contract is `passed_fresh_radial_binding_source_review`, with
exact `sources` (BIND/MODEL/REFERENCE/COLLECT), `manifest` and `inputs` pins.
Root candidate acceptance is `accepted_joint_candidate_for_fresh_W9_radial`,
with `fit_result`, `selected`, `fit_review`, `regression_result`,
`regression_report`, `all25_passed: true`, `complete_consumed_cycles: 8`, and
`candidate_frozen_before_fresh_outcomes: true`. It is not an execution release.
