# Canonical terminal-amide scope inventory

## Frozen question and identity rule

Can the same chemically defined terminal-amide alternative be represented for the **exact 25 already-consumed canonical records** of the completed frozen-vacuum-charge ALPB candidate? This is a source/mapping inventory, not an energy experiment, alternative selection rule or new benchmark. Preserve every canonical record, its actual source/context identity and current state. Do not inspect class outcomes to choose residues.

Use only each source's already-declared fixed-core `requested_roles.anchor_asparagine` identity, the role used by the existing source-dihedral machinery. A neutral ASN or GLN at that role is a candidate for inventory. ASN uses the real CB–CG terminal axis and OD1/ND2/two ND2-bound H atoms; GLN uses CG–CD and OE1/NE2/two NE2-bound H atoms. GLN is the analogous terminal-amide chemistry, not permission to change another residue into Asn. Preserve the carbonyl carbon on the axis and all atom identities. This inventory constructs neither flip.

Do not choose the nearest amide, impose a new proximity cutoff, replace a missing role with a remote ASN/GLN, or omit a source because its current oxygen/nitrogen orientation is unfavorable. The historical role assignment establishes the proximal donor context; it is not proof of a favorable current contact. Nonamide/absent roles and incomplete states/maps remain explicit.

Metadata collection and hashing may run on login. All graph interpretation, coordinate parsing, geometry calculations or scientific imports, if needed, run in a root-submitted one-CPU Slurm inventory. No MACE, GFN2, native ALPB, DFT, optimization, coordinate changes, classifier evaluation or calibration changes. Existing failed preparations and old outcomes stay immutable.
