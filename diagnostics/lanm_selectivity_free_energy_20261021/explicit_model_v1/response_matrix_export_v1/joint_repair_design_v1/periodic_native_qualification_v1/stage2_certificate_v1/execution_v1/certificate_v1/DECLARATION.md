# One changed-state certificate producer

This source-only adapter completes the already declared 32-state Stage2 plan. It changes no native source, frozen geometry, candidate, PME recipe, threshold, solver, or completed central result. Each separately released job consumes one completed changed-state initializer after the central/bypass scout passes. It performs one assembly and one nominal static factor, retaining every incomplete or failed phase. No native program runs here. Root owns all numerical releases and queue checks.

The immutable execution manifest df799cfb remains the build/native authority. The new producer and helper pins are separately reviewed and bound in each configuration/release. A certificate binds the literal source/runtime inputs, native build, initializer state and PME output, assembly arrays, and factor readbacks. Native gradient execution still requires root admission of this exact state certificate and compares the full initialized native state before PCG. Central initializer/factor work is not repeated.

Assembly reuses qualified ASSEMBLE.py, with literal cell sides for the 32 frozen geometries, all positive intrinsic alpha values, existing Thole/POLPAIR overrides and all-unity mutual scales from the admitted composition metadata. It includes the complete 3980-water compact-response collective sigma and normalized metal H. The already reviewed Stage1 raw state reader is copied unchanged; its compact-response reconstruction changes only the cell argument replacing fixed49.324. Native h/H/damping/PME are compared under the inherited 1e-11 scaled parity criterion. No fixed displaced graph or nnz is assumed. Pair query is inside the assembly memory/time scope; it can fail before a useful matrix exists.

The assembly child has one numerical thread, 8 GiB address-space limit, 4 GiB array budget, 180 wall/CPU seconds. Its canonical lower CSC is exported unshifted. The separate factor child uses the existing fixed supernodal LL/AMD backend, writable index copies, 12 OpenBLAS threads and one OpenMP thread; 32 GiB address space, 900 wall seconds and10800 CPU seconds. The actual Slurm allocation must be one node, one task, 12 CPUs with default48000 MiB. This is a per-static-state engineering route, not MD-step feasibility.

Use the same nominal shift tau=1e-6*(U_B+U_R)+delta_odd, where U_B belongs to this exact assembly and U_R/delta_odd belong to this exact initialized PME snapshot. e_app remains null and unestablished. One symbolic and one numeric attempt only, no ordering/mode retry. Any backend error or warning discards the factor before solves. The unchanged copied-L/permutation and ten fixed sampled action/solve checks use100*N*eps. Failure is preserved as insufficient or failed numerical evidence, not proof of full-PME instability. This remains ordinary-double nominal evidence, not an interval certificate.

Before any actual state execution, finite controls are limited to AST correspondence of copied pure functions, tiny manufactured compact-response/cell metadata, exact binding/error rejection, and cap/persistence source checks. They do not assemble, invoke a backend, or read actual state output numerically. No existing qualification suite is repeated.
