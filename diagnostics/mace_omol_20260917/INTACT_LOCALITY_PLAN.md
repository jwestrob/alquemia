# Saved-output locality audit of the whole-chain descriptor

Declared 2026-09-17 after the five-case development results and before this
decomposition. Authorized by Jacob's active MACE goal and blanket research
permission. This is explanatory development work, not a new prediction test.

Question: which portions of the intact representation contribute to the
matched bound-minus-detached score? This helps distinguish removing chemical
caps and retaining local protein context from a claim of full long-range
protein electrostatics. It cannot by itself separate total-charge conditioning
from geometry or establish a unique physical mechanism.

Use every primary endpoint in the completed five-case intact_report_v1, its
original coordinate mappings, actual receipts and saved native node/embedding
readouts. No model forward, force, coordinate change, label change, threshold
or new scientific state. Preserve the existing numerical tolerance, 0.01
kcal/mol, for sum closure. The native learned atomic terms are bookkeeping,
not unique observable atomic energies.

For each metal retain the vector of native node changes between bound and
detached states. Form the score vector as delta_node_Ca minus delta_node_La,
with one eV-to-kcal conversion. Audit embedding and atomic-reference changes
separately. Group every atom by its original source residue, chemical kind,
and fixed radial shells from the bound metal: metal itself, 0–6, 6–12, 12–18,
and beyond18 Angstrom. Shells come from the pinned6 Angstrom cutoff and three
interaction blocks, not observed contribution sizes. Report maximum absolute
and summed absolute changes beyond18 Angstrom as well as signed sums; do not
hide cancellation. Retain atom counts, identities, distances and all terms.

Verify paired atom order/positions, fixed bound/detached charges, unchanged
nonmetal coordinates, isolated detached metal, actual execution receipts and
native readout sums. Recover input tasks from each endpoint's own manifest,
including reused alpha endpoints. Missing/corrupted inputs fail explicitly.
Compare the summed contributions to each archived R_coord and all three
archived cross-protein contrasts. No alternative truncated score or promotion.

Five consumed cases,20 existing endpoint readouts,zero new energy evaluations.
Run on CPU with the existing environment; record local timing. This audit does
not require a GPU reservation. Results and source snapshot go under a new
workspace; a compact interpretation goes beside this plan.
